# STUPUL GENESIS v2.0 — Metrici de Creștere a Utilizatorilor

Data: 24.10.2026 · Auditor: Cline

## 1. Principii
- Colectăm **minimul necesar**, cu informare și temei legal (GDPR).
- **Nu** folosim date false pentru a demonstra retenție/viralitate.
- Metrici doar pentru experimente oneste (praguri stabilite înainte de test).

## 2. Metrici propuse (primii 100 de testeri, fără publicitate plătită)
| Metrică | De ce | Instrument |
|---|---|---|
| Vizitatori | interes | analytics minim/consimțământ |
| Începerea primei sesiuni | onboarding | eveniment local |
| Finalizarea primei misiuni | activare | stare joc |
| Prima contribuție | participare | server |
| Prima proprietate | angajament | server |
| Revenire D1 / D7 | retenție | identificator anonim |
| Distribuire voluntară (share link) | viralitate etică | link cu parametru |
| Erori | stabilitate | log client/server |
| Cereri API / consum D1 | costuri free-tier | server |

## 3. Mecanism de distribuire original (pregătit)
Un jucător poate trimite un link către o **provocare concretă** sau un **proiect comunitar**.
Destinatarul inspectează fără cont, participă conform regulilor și își vede contribuția în oraș.
Fără condiționarea progresului de invitații; fără bucle compulsive.

## 4. Anti-compulsie
Fără streak-uri punitive, countdown FOMO, penalități de absență, notificări agresive, slot-mechanics.
